You will start with a recording or synthetic RF example, create a curated dataset, launch a training run, export a model artifact, package an application, and view it in Screens. The path mirrors the tested journey in the product: upload recording, curate, train, and export.

## Next steps

Work through the tutorials in order to complete the full path:

1. [Synthesis and Local Capture](/guides/tutorials/synthesis-and-local-capture/) — create source RF data
2. [Creating Recordings](/guides/tutorials/create-recordings/) — generate SigMF recordings with the CLI
3. [Curation and Labeling](/guides/tutorials/curation-and-labeling/) — build a labelled training dataset
4. [Basic Training Materials](/guides/tutorials/basic-training-materials/) — understand dataset requirements
5. [Inspect a Dataset](/guides/tutorials/inspect-a-dataset/) — verify dataset quality before training
6. [Train a Model](/guides/tutorials/train-a-model/) — launch a Model Builder run
7. [Package an Application](/guides/tutorials/package-an-application/) — connect artifacts into a deployable pipeline
8. [Screens App](/guides/tutorials/screens-app/) — run the finished app
