This tutorial is the smallest possible Composer-to-Screens path. It assumes you already have a trained `best.onnx` artifact in a RIA Hub repository — see [Train a Model](/guides/model-builder/train-a-model/) if you don't.

<PipelineGraph workflow="capture-to-screens" activeNode="package" />

## Step 1 — Open Application Composer

From the top nav, click **Application Packager → Application Composer**. The page is the graph-based editor that turns a trained artifact into a deployable application JSON. See [Application Composer](/guides/application-packager/application-composer/) for the full surface tour.

## Step 2 — Compose the smallest pipeline

Drag four blocks from the **Available Blocks** sidebar:

1. A `source` (RadioSource or a synthetic source).
2. A `preprocessing` block matching the feature representation your model was trained on.
3. An `inference` block. Double-click it and set `model_path_map` to the path of your `best.onnx`.
4. A `sink` (display or network).

Connect them left-to-right: `source → preprocessing → inference → sink`. The [Application Composer reference](/guides/application-packager/application-composer-reference/) lists every spec required per block type.

## Step 3 — Pick the target and build

In the toolbar:

- Set **Target Build Repo** to the repository that should receive the application JSON.
- Set **Target Profile** to **RIA Hub Screens (Web App)** (`ria-screens`).
- Click **Build Application**.

Composer validates the graph, generates a Screens manifest at `screens/<app-name>/manifest.json`, bundles the model into a tarball, and populates the commit form.

## Step 4 — Commit

Fill the commit message and click **Commit Changes**. The application JSON and manifest are now in your target repository, and the app is ready to run.
