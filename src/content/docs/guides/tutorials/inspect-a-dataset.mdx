## What to Fix Before Training

<CollapsibleList
	title="Inspector troubleshooting"
	items={[
		{ title: 'Imbalanced classes', body: 'Collect, synthesize, or curate more examples for minority classes before trusting comparisons.' },
		{ title: 'Missing metadata', body: 'Check source OIDs, label names, qualifiers, sample shape, and split fields.' },
		{ title: 'Too few examples', body: 'Avoid launching a run when each class has only a handful of slices unless the task is explicitly a smoke test.' },
		{ title: 'Invalid split assumptions', body: 'Confirm that train and validation examples do not leak from the same source interval when independence matters.' },
	]}
